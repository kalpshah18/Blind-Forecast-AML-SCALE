# Blind Forecast: write-up

**What worked.** I modelled scaled anomalies from a per-station harmonic climatology with L1 losses, and blended a per-station LAD regression, LightGBM and a pooled MLP with a station embedding. The MLP was the best single model (local CV 0.625, against 0.637 for LightGBM and 0.641 for LAD) and takes about 80% of the blend weight.

The largest gain came from noticing that the test windows do not resemble the training period. Their anomalies against the training climatology are far from zero: S8, for example, runs about 4 degrees C hotter in tmax. Models trained on zero-mean anomalies treat that offset as weather and let it decay. Fitting a seasonal per-station offset from the unlabelled test inputs moved the public score from 0.736 to 0.688. Six seeds with shift and scale augmentation during training, plus the MLP, brought it to 0.675. In a simulation that injected the estimated shifts into validation windows, the correction matched an oracle that knew the true shift, which is why I believe it is a real effect and not a fit to the public board.

**What didn't.** An analog forecaster (0.682) received almost no blend weight. A GRU was worse than the MLP in every fold. Larger and smaller MLPs were both worse, so capacity looks about right. More climatology harmonics gained 0.0005. Choosing the offset's harmonic order per cell looked good on held-out test inputs but scored worse on the public board (0.680), so I dropped it. Removing the dispersion correction changed nothing (0.675), probably because the augmented network already handles scale. Larger augmentation with 12 seeds did not help (0.676). Backtesting inside the test windows, with days -9 to -5 forecasting days -4 to 0, showed that fitted forecast gains do not generalise: the forecasts are already calibrated in the shifted regime. I think that is why further tuning stopped paying.

**Caveats.** Local CV cannot see the shift, so those choices rest on simulation and the noisy public board. Differences below about 0.002 are not meaningful. Using the test inputs for adaptation is a disclosed transductive choice. No external data was used.
